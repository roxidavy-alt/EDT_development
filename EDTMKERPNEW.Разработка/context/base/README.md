# Контекст основной конфигурации

Файлы в этой папке выгружены из основной конфигурации только для анализа.

Правила:
- не изменять файлы в context/base;
- изменения делать только в src проекта расширения EDT;
- если нужно изменить объект основной конфигурации, сначала описать требуемое изменение текстом;
- новые объекты метаданных расширения сначала создавать в EDT.
